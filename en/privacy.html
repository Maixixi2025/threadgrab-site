Privacy Policy

Last updated: June 6, 2026

This page explains what data ThreadGrab collects when you use the thread archive tool, and what we don't.

1. What we do NOT collect

  • Your X/Twitter credentials — we never ask for them, we don't have them, and we can't access your account.
  • Your IP address for tracking — Cloudflare logs IPs for security, not for advertising or analytics resale.
  • Personal identifiers — no email, no name, no cookies for cross-site tracking.

2. What we DO collect (minimal)

  • Thread URL you submit — stored temporarily to fetch the thread content. Not associated with any user identity.
  • Public thread content — stored in our archive so it can be served back to you and to anyone with the archive link. This is the entire point of the tool.
  • Cloudflare logs — IP, user agent, requested URL. Standard security and abuse prevention logs. Retained per Cloudflare's policy.

3. How we use the data

  • Thread URL: to fetch the public thread content via X's public API or scraping the public web view.
  • Thread content: to serve you the converted output and to maintain a permanent archive of public discussions.
  • Cloudflare logs: to detect abuse, rate-limit bots, and protect the service.

4. Cookies

ThreadGrab does not set first-party cookies. Cloudflare may set security cookies (e.g., __cf_bm for bot detection). No advertising cookies, no analytics cookies, no cross-site tracking.

5. Third parties

  • Cloudflare (CDN and security): see Cloudflare Privacy Policy.
  • X / Twitter: we fetch public thread content via X's public-facing endpoints. X's privacy policy applies to data they collect when we make requests: twitter.com/en/privacy.

6. AI / LLM use

ThreadGrab's archive is intended to help AI tools reference public discussions for citation purposes. We publish an llms.txt file at /llms.txt that explicitly allows AI crawlers. We do not sell or license thread data to AI companies separately.

7. Children's privacy

ThreadGrab is not directed at children under 13. We do not knowingly collect data from children.

8. Changes to this policy

Material changes will update the "Last updated" date above. Continued use of the tool after changes constitutes acceptance.

9. Takedown requests

If you are the author of an archived thread and want it removed, contact us via the with the thread URL. We will action legitimate takedown requests within 7 days.

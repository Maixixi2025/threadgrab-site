tweet.md vs ThreadGrab: Ferramentas de Thread X para Markdown

23 de Junho, 2026 · 9 min de leitura · Comparação

Em junho de 2026, duas ferramentas dominam o nicho de converter threads do X (Twitter) em Markdown limpo: tweet.md — um web app minimalista de colar URL em tweet.md — e ThreadGrab — um downloader multiplataforma e conversor para Markdown que atende X, Bluesky e LinkedIn. Compartilham uma proposta de valor de uma linha, mas divergem muito no que realmente entregam.

Esta comparação detalha as diferenças em fidelidade de saída, cobertura de plataformas, história de automação e propriedade dos dados. No final, você saberá qual ferramenta combina com seu fluxo — e quando usar as duas juntas.

Resumo. tweet.md é um web app rápido e de propósito único para transformar uma URL de thread do X em Markdown — sem conta, sem instalação, UX de colar-link. ThreadGrab é um aplicativo para download, multi-plataforma, que captura conteúdo social do X, Bluesky e LinkedIn com modo batch, arquivamento de perfil e propriedade local completa. Se você só precisa de uma thread avulsa do X, tweet.md é mais rápido. Se precisa de automação, captura multi-plataforma ou arquivos locais, ThreadGrab é a melhor escolha.

O que tweet.md Faz Bem

tweet.md é um web app de uma tela. Você cola a URL de uma thread, ele busca os dados públicos e mostra um preview limpo em Markdown. Não há cadastro, instalação ou página de configurações. Se sua necessidade é “pegar essa thread que meu amigo mandou e encaminhar como Markdown”, a ferramenta entrega isso em menos de cinco segundos.

Também acerta o básico: ordenação da thread, handle do autor, timestamps e hierarquia de headings. Para usuários casuais que preferem Markdown em vez de screenshots, a UX sem fricção é uma vitória real.

Onde tweet.md Fica Curto

  • Sem modo batch. Cada thread é uma colada separada. Pesquisadores e jornalistas que lidam com dezenas de threads por semana perdem horas.
  • Sem download de mídia. URLs de imagem e vídeo continuam hospedadas no X. Se o post original for deletado, seu Markdown perde os visuais.
  • X Articles achatados. Posts longos do X (layout v11.90) perdem estrutura: imagens de capa, quebras de seção, blocos de entidades viram texto plano.
  • Sem arquivo local. A saída está na aba do navegador. Se fechar, o Markdown some, a menos que tenha copiado.
  • Apenas X. Threads do Bluesky e newsletters do LinkedIn não são suportadas.

O que ThreadGrab Faz Bem

ThreadGrab é um app CLI e GUI instalável, voltado para o stack completo de conteúdo social: X, Bluesky e LinkedIn. A mesma ferramenta que captura uma thread também cuida de arquivamento de perfil, jobs em batch e saída Markdown local com frontmatter adequado.

Para quem trata conteúdo social como base de conhecimento — escritores de newsletter, curadores de dados de treino de IA, pesquisadores, arquivistas — a abordagem local-first compensa na hora. Seus arquivos Markdown vivem no seu disco, versionados no seu repositório git, indexados pela sua ferramenta de busca.

Onde ThreadGrab Brilha Sobre tweet.md

1. Captura Multi-Plataforma

Uma ferramenta, três plataformas. O mesmo padrão de comando ThreadGrab funciona para threads do X, threads de post do Bluesky e capturas de newsletter do LinkedIn.

# Thread do X para Markdown
threadgrab thread https://x.com/paulg/status/1234567890

# Thread de post do Bluesky para Markdown
threadgrab thread https://bsky.app/profile/jack.bsky.social/post/abc123

# Artigo de newsletter do LinkedIn
threadgrab thread https://www.linkedin.com/pulse/some-article

2. Modo Batch e Perfil

Cole uma lista de URLs ou passe um handle de perfil. ThreadGrab percorre a timeline do perfil e salva cada thread como um arquivo Markdown separado.

# Arquivar um perfil completo do X em ./archive/
threadgrab profile paulg --output ./archive/ --since 2026-01-01

# Captura em batch a partir de uma lista
cat urls.txt | threadgrab batch --format markdown

# Salvar perfil + mídia
threadgrab profile naval --with-media --output ./naval-archive/

3. Preservação do Layout X Articles v11.90

X Articles têm estrutura complexa: imagem de capa, blocos de texto com entidades nomeadas, citações em destaque, divisores de seção. ThreadGrab interpreta o novo layout v11.90 e preserva a estrutura como headings, blockquotes e referências de imagem em Markdown. tweet.md achata tudo em um único bloco de texto.

4. Download Local de Mídia

Toda imagem e vídeo referenciado em uma thread é baixado junto com o arquivo Markdown. Se o post original for deletado, seu arquivo continua funcionando.

archive/paulg-2026-06-15/
  thread.md
  media/
    01-cover.jpg
    02-chart.png
    03-video.mp4

5. Saída JSON para Pipelines

Precisa de saída legível por máquina para um pipeline downstream? ThreadGrab emite Markdown e JSON estruturado, então a mesma captura alimenta um vault Obsidian e um conjunto de treino de LLM.

Usando as Duas Ferramentas Juntas

Elas não são excludentes. Um fluxo comum é: tweet.md para compartilhar avulso, ThreadGrab para o arquivo de longo prazo. Cole uma URL no tweet.md se quiser um preview rápido em Markdown. Quando a thread se mostrar valiosa, rode ThreadGrab para baixar a versão completa com mídia e frontmatter adequado na sua base de conhecimento.

# Passo 1: Preview rápido via web app tweet.md (navegador)
# — copie o Markdown se quiser colar em um chat

# Passo 2: Arquivo permanente via ThreadGrab
threadgrab thread https://x.com/paulg/status/1234567890 \
  --output ~/knowledge/threads/ \
  --with-media \
  --frontmatter

FAQ

tweet.md é gratuito?

Sim. tweet.md é um web app gratuito sem necessidade de conta. Você cola uma URL de thread e a página renderiza o Markdown.

ThreadGrab é gratuito?

Sim. ThreadGrab é open-source e gratuito para uso local. Você roda na sua própria máquina, sem limites de API ou cobrança por thread.

tweet.md lida com X Articles (posts longos)?

Parcialmente. Converte o texto do artigo em Markdown, mas achata o layout v11.90 — imagens de capa, divisores de seção e blocos de entidades viram parágrafos simples. ThreadGrab preserva a estrutura completa.

ThreadGrab consegue raspar contas privadas ou protegidas?

Não. tweet.md e ThreadGrab trabalham com conteúdo publicamente disponível. Para contas protegidas seria necessário acesso autenticado à API, fora do escopo das duas ferramentas.

Qual ferramenta é melhor para pesquisadores arquivando centenas de threads?

ThreadGrab. Modo batch, handles de perfil, arquivos locais e saída JSON tornam a ferramenta certa para arquivamento sistemático. tweet.md é um web app por thread e fica impraticável em escala.

ThreadGrab armazena meus dados em um servidor?

Não. ThreadGrab é um aplicativo local. Todos os arquivos de saída são gravados em um diretório que você escolhe. Não há conta na nuvem ThreadGrab nem armazenamento remoto das suas capturas.

Duas Ferramentas, Objetivos Diferentes

tweet.md é um web app de uma tela para o momento casual de “me manda essa thread como Markdown”. ThreadGrab é uma ferramenta instalável e scriptável para quem trata conteúdo social como base de conhecimento. Se sobrepõem no caso de thread única e divergem em todo o resto: cobertura de plataformas, automação, manuseio de mídia e propriedade dos dados.

Escolha tweet.md quando a fricção de instalar uma ferramenta pesa mais do que o tempo economizado. Escolha ThreadGrab quando você precisa de captura multi-plataforma, jobs em batch ou arquivos locais. As duas se complementam — use tweet.md para compartilhamentos rápidos, ThreadGrab para o arquivo de longo prazo.

Arquivamento Mastodon Fediverse 2026: 5 Formas de Salvar Posts, Mídias e Feeds

1 de Agosto de 2026 · 11 min de leitura · por ThreadGrab

Mastodon e o restante do Fediverso cruzaram um ponto de virada em 2026. Apenas o mastodon.social atende mais de 3,3 milhões de usuários ativos mensais com 183 milhões de statuses publicados; instâncias especializadas como fosstodon.org, hachyderm.io e mastodon.online adicionam mais de 300 mil usuários entre elas. Seja você um jornalista rastreando uma notícia urgente, um pesquisador construindo um conjunto de dados longitudinal, ou um criador de conteúdo reaproveitando seus próprios posts para um artigo longo, você precisa de uma forma confiável de arquivar conteúdo do Mastodon antes que uma instância desligue ou um moderador apague um fio.

O Fediverso roda em ActivityPub -- o mesmo protocolo que alimenta Mastodon, Misskey, Pleroma, Akkoma, Ghost, PeerTube e Pixelfed. Essa base compartilhada torna o arquivamento baseado em ActivityPub mais fácil do que raspar qualquer plataforma proprietária, porque cada nó expõe APIs públicas compatíveis. Este guia cobre cinco métodos comprovados para arquivar posts, mídias e feeds inteiros de instâncias do Mastodon em 2026, dos bookmarks ao scraping completo de federação.

Resumo. Use bookmarks nativos do Mastodon para salvamentos casuais. Use a API REST do Mastodon para acesso programático sem autenticação. Use o ThreadGrab para arquivamento multiplataforma (Mastodon + X + Bluesky em uma única interface). Use o toot CLI para fluxos de trabalho em terminal. Use o Mastodon-CLI para exports pesados e backups em nível de instância.

Por que o Arquivamento do Mastodon Importa em 2026

Três tendências tornam o arquivamento do Mastodon especialmente urgente este ano. Primeiro, a população do Fediverso quase triplicou desde o éxodo do Twitter em 2022, com instâncias individuais hospedando regularmente 60k-300k usuários e milhões de posts públicos. Segundo, instâncias podem desaparecer da noite para o dia: um moderador voluntário se esgota, contas de hospedagem não são pagas, ou uma única queixa DMCA aciona o desligamento do servidor, levando cada post público junto. Terceiro, o design aberto do ActivityPub significa que não há chave de API, paywall ou registro de desenvolvedor necessário para acesso de leitura em conteúdo público -- qualquer ferramenta que fale HTTP pode arquivar o Fediverso.

Diferentemente do X, que restringe acesso à API em níveis pagos, e do Instagram ou TikTok, que bloqueiam endpoints de leitura por gating de apps aprovados, servidores ActivityPub publicam toda sua timeline pública por HTTP livre. Você não precisa registrar um app, não precisa se inscrever, e não precisa pagar ninguém. Isso torna o Fediverso a rede de conversa pública mais arquivável em 2026.

Método 1: Bookmarks Nativos do Mastodon -- O Salvamento Sem Esforço

Bookmarks Nativos do Mastodon

Disponível em todo app oficial do Mastodon (web, iOS, Android, clientes terceiros) desde Mastodon 4.0 (2023).

Prós: Configuração zero, privado, pesquisável dentro da sua conta, funciona em qualquer app oficial.

Contras: Sem export pela UI web, bookmarks vivem e morrem com sua conta, sem operações em lote, sem mídia anexada.

Mastodon introduziu bookmarks na versão 4.0 (novembro de 2023), e funcionam como qualquer outro bookmark social que você já usou. Clique no ícone de bookmark em qualquer post, e ele é salvo em uma lista privada visível apenas para você. Bookmarks são pesquisáveis na UI web e nos apps móveis oficiais, e sincronizam entre dispositivos se você fizer login na mesma conta.

Bookmarks são perfeitos para uso casual -- você vê um fio interessante no seu feed principal, marca, e volta mais tarde para reler. Mas têm um teto máximo: não há botão de export. Se você quer migrar, compartilhar ou analisar sua coleção de bookmarks, precisa ou da API (Método 2) ou de uma ferramenta de terceiros (Métodos 3-5).

Quando usar bookmarks nativos

  • Você salva posts ocasionalmente e apenas os relê dentro do Mastodon.
  • Você usa Mastodon em vários dispositivos e quer listas de leitura sincronizadas.
  • Você não precisa do conteúdo salvo fora do Mastodon, e confia na confiabilidade de longo prazo da sua instância.

Método 2: API REST do Mastodon -- A Abordagem Aberta, Sem Auth

API Pública do Mastodon (v1 + v2)

URL base: https://<instância>/api/v1/ e .../api/v2/ -- endpoints de leitura não exigem autenticação.

Prós: Completamente grátis, sem registro de app, bem documentado em docs.joinmastodon.org, funciona com qualquer cliente HTTP.

Contras: Rate-limit por IP (300 requests por 5 minutos na maioria das instâncias), exige familiaridade com vocabulário ActivityPub, binários de mídia precisam de fetches separados.

Toda instância Mastodon expõe uma API REST que espelha de perto a UI web do Mastodon. Você pode buscar timelines públicas, statuses individuais, feeds de hashtag, resultados de busca, e listagens de diretório de instância -- tudo com simples HTTP GET requests e sem login. A superfície da API é estável entre instâncias porque todo servidor implementa o mesmo código Mastodon.

# Buscar a timeline local de qualquer instância Mastodon
curl -s "https://fosstodon.org/api/v1/timelines/public?limit=3" \
  | jq '[.[] | {user: .account.username, content: .content[0:120]}]'

# Buscar um status específico pelo ID numérico
curl -s "https://mastodon.social/api/v1/statuses/113305367338692164" \
  | jq '{id: .id, user: .account.username, content: .content[0:200]}'

# Buscar através do índice local de qualquer instância
curl -s "https://mastodon.social/api/v2/search?q=ActivityPub+archiving&limit=10" \
  | jq '.statuses[] | {user: .username, content: .content[0:120]}'

O conceito chave no modelo de dados do Mastodon é o ID numérico (um inteiro de 64 bits, frequentemente renderizado como Snowflake). Todo status, conta e anexo de mídia tem um ID estável. Uma vez que você tem uma URL de status, pode extrair a instância e o ID e buscar o mesmo post de qualquer ferramenta que fala a API REST. Diferentemente das atividades assinadas ActivityPub, a API REST é uma superfície JSON-only mais simples feita para apps cliente.

Rate limits são aplicados por IP e por token de acesso, com a maioria das instâncias padronizando em 300 requests por janela de 5 minutos para tráfego não autenticado. Para arquivamento pessoal, um cron job diário fica bem dentro do limite. Para coleta em larga escala, você precisa de um token de acesso (faça login uma vez, salve o token) ou de uma ferramenta de crawling de federação.

Quando usar a API REST do Mastodon

  • Você está confortável com curl ou uma linguagem de script como Python ou Node.js.
  • Você quer puxar JSON para análise downstream (ingestão LLM, construção de dataset, migração de conteúdo).
  • Você só precisa de conteúdo público, e não se importa de pular mídia ou posts com login.

Método 3: ThreadGrab -- Arquivamento Multiplataforma Mastodon + X + Bluesky

ThreadGrab

Site: threadgrab.com -- grátis, sem necessidade de conta, sem registro de app.

Prós: Interface única para arquivamento Mastodon E X E Bluesky, API pública grátis, sem autenticação para chamadas de leitura, retorna JSON ou Markdown normalizado.

Contras: Requer conforto básico de linha de comando, não faz scraping de firehose de federação completo (use Mastodon-CLI para isso).

ThreadGrab foi construído para resolver um problema persistente em conteúdo social: cada plataforma tem sua própria API, seu próprio modelo de autenticação, seus próprios rate limits e seu próprio vocabulário de dados. A API REST do Mastodon é JSON, a API do X é JSON, mas os nomes de campo, convenções de paginação, e formatos de entidade são todos diferentes. ThreadGrab normaliza tudo em um único formato de resposta, então o mesmo script que arquiva um fio do X pode arquivar um toot do Mastodon sem modificação.

# Arquivar qualquer conta Mastodon via ThreadGrab (sem login)
curl -s "https://threadgrab.com/api/mastodon/account/mastodon.social/mastodon" \
  | jq '.[:3] | .[] | {user: .user, text: .text[0:120], url: .url}'

# Salvar posts do Mastodon como Markdown para um arquivo LLM-friendly
curl -s "https://threadgrab.com/api/mastodon/account/mastodon.social/mastodon" \
  | jq -r '.[] | "## @\(.user)\n\(.text)\n---\n"' \
  > mastodon-arquivo-$(date +%Y-%m-%d).md

# Buscar posts no Fediverso por palavra-chave
curl -s "https://threadgrab.com/api/mastodon/search?q=ActivityPub&instance=fosstodon.org&limit=10" \
  | jq '.posts[] | {user: .user, text: .text[0:100]}'

Como todo servidor Mastodon implementa os mesmos endpoints REST, ThreadGrab pode perguntar qual instância você quer consultar e rotear a request automaticamente. Você não precisa aprender a diferença entre o deploy de mastodon.social e o de fosstodon.org -- eles expõem a mesma superfície de API, então ThreadGrab os trata identicamente.

O output é JSON limpo que você pode transformar em qualquer formato: Markdown para posts de blog e contexto LLM, CSV para análise em planilha, texto simples para indexação em busca. Posts Mastodon incluem a URL original, o handle do autor (com sua instância, ex. @user@fosstodon.org), e um timestamp normalizado que você pode ordenar contra conteúdo de outras plataformas.

Quando usar ThreadGrab

  • Você arquiva conteúdo de Mastodon, X, e Bluesky e quer uma ferramenta que fale os três.
  • Você precisa de output Markdown limpo para treinamento LLM, pipelines RAG, ou bases pessoais de conhecimento.
  • Você não quer gerenciar tokens de autenticação por instância.

Método 4: toot CLI -- O Kit de Ferramentas do Usuário Avançado de Terminal

toot (CLI para Mastodon)

pip install toot -- o CLI Mastodon de terceiros mais popular, escrito em Python.

Prós: Paridade total de features com a UI web, login é um comando, feito para script, funciona com qualquer instância.

Contras: Requer registrar um app Mastodon (um clique em configurações), adiciona dependência Python, menos ergonômico para exports em massa.

toot é o CLI de facto para Mastodon. Expõe a API completa de leitura e escrita em um shell amigável: toot post publica um status, toot timeline imprime sua timeline, toot search executa uma busca por palavra-chave. Para arquivadores, os comandos toot bookmark, toot whois, e toot search são particularmente úteis porque permitem triagem e captura de conteúdo sem sair do terminal.

# Instalar e fazer login (execute uma vez)
pip install toot
toot login --instance fosstodon.org
# Uma janela do navegador abre; copie o código de auth de volta; toot armazena localmente

# Buscar e salvar os primeiros 5 resultados
toot search "ActivityPub arquivo 2026" --limit 5 \
  | tee mastodon-busca-2026-08-01.txt

# Listar seus bookmarks programaticamente (ótimo para preencher um arquivo)
toot bookmarks --limit 20 | tee meus-bookmarks.txt

# Inspecionar qualquer usuário -- seguidores, bio, contagem de posts
toot whois --user @Gargron@mas.to | head -40

toot gerencia o armazenamento do token de login para você, então só precisa autenticar uma vez por instância por dispositivo. É um companheiro brilhante para um pipeline de shell: direcione toot search para jq, depois para tee, e você tem um script de arquivo diário em 4 linhas.

Quando usar o toot CLI

  • Você vive em um terminal e quer acesso Mastodon sem uma aba de navegador.
  • Você quer autenticar uma vez e usar o mesmo token para postar, marcar e ler.
  • Você está construindo um pipeline de arquivo baseado em shell (cron, bash, fish, zsh).

Método 5: Mastodon-CLI -- Exportações em Massa e Backups em Nível de Instância

Mastodon-CLI + tarefas rake (ferramentas admin)

npm install -g mastodon-cli para não-admins, ou RAILS_ENV=production tootctl media backfill para admins.

Prós: Operações em massa, suporta centenas de milhares de posts por sessão, captura binários de mídia, inclui backup admin para instâncias inteiras.

Contras: Setup mais pesado que outros métodos, Mastodon-CLI é menos mantido ativamente que toot, backups em nível de instância exigem acesso admin.

Quando você precisa arquivar milhares de posts -- ou o conteúdo inteiro de uma instância -- você pega o Mastodon-CLI ou as tarefas rake oficiais tootctl. Mastodon-CLI é uma ferramenta Node.js que fornece variantes batch-friendly dos endpoints REST comuns, com lógica de retry e suporte a resume para exports longos.

# Instalar Mastodon-CLI globalmente
npm install -g mastodon-cli

# Login uma vez (baseado em env, seguro para cron)
export MASTODON_TOKEN="<seu...export MASTODON_INSTANCE="https://fosstodon.org"

# Arquivar uma conta inteira como JSON
mastodon-cli archive @Gargron@mas.to --format json \
  --output gargron-arquivo.json

# Salvar todo post que menciona uma hashtag como Markdown
mastodon-cli hashtag "ActivityPub" --format markdown --limit 200 \
  > fediverse-activitypub-arquivo-md.txt

# Para admins de instância: dump completo (statuses + mídia + DB)
tootctl media backfill --concurrency 20
tootctl backup --path /var/backups/mastodon/

Para usuários não-admin, o ponto doce do Mastodon-CLI são capturas em massa em nível de hashtag e conta -- ele pode puxar milhares de posts em uma única sessão, com retry embutido em rate limits e relatório de progresso. Para admins, as tarefas rake tootctl incluídas são a forma canônica de fazer backup de uma instância antes de uma migração ou desligamento de servidor.

Quando usar Mastodon-CLI / tootctl

  • Você precisa arquivar mais que um dia de posts de um usuário ou hashtag.
  • Você está fazendo migração de instância e precisa de backup amplo do servidor.
  • Você quer baixar binários de mídia, não apenas conteúdo de texto.

Construindo um Pipeline Completo de Arquivamento Mastodon

Aqui está como um criador de conteúdo pode combinar esses métodos em um workflow diário de arquivamento Mastodon que também captura X e Bluesky:

#!/bin/bash
# Pipeline diário de arquivamento Fediverse + X + Bluesky (cron às 7h)
# Combina ThreadGrab API para pulls multiplataforma + armazenamento em arquivo

MASTODON_INSTANCE="fosstodon.org"
ACCOUNTS=("Gargron@mas.to" "mcpheywood@mastodon.social" "fosstodon@fosstodon.org")
OUTPUT_DIR="$HOME/fediverse-arquivo/$(date +%Y/%m)"
mkdir -p "$OUTPUT_DIR"

for acct in "${ACCOUNTS[@]}"; do
  HANDLE="${acct%@*}"
  curl -s "https://threadgrab.com/api/mastodon/account/${MASTODON_INSTANCE}/${HANDLE}" \
    | jq -r '.[] | "### @\(.user)\n\(.text)\n---\n"' \
    > "$OUTPUT_DIR/mastodon-$HANDLE.md"
  echo "Salvo Mastodon $acct: $(wc -l < "$OUTPUT_DIR/mastodon-$HANDLE.md") linhas"
done

echo "Arquivo Fediverse completo para $(date +%Y-%m-%d)"

Este pipeline roda diariamente via cron, organiza arquivos por ano e mês, e usa ThreadGrab porque o mesmo script também pode arquivar handles do Bluesky e perfis do X sem modificação -- apenas a URL muda. O jornalista pode então alimentar o arquivo Markdown em um LLM para sumarização, busca ou detecção de tendências através do Fediverso.

Dica pro. Para máxima flexibilidade, combine ThreadGrab para leituras multiplataforma, a API REST do Mastodon para investigação pontual, e toot para bookmarking no terminal durante eventos ao vivo. ThreadGrab gerencia a normalização Fediverse + X + Bluesky; a API nativa e o CLI dão controle total quando você precisa.

Perguntas Frequentes

Mastodon tem bookmarking nativo como Bluesky?

Sim. Mastodon tem bookmarks nativos desde a versão 4.0 (final de 2023). São privados e pesquisáveis dentro da sua conta, mas diferentemente do Bluesky você não pode exportá-los pela UI web -- precisa de uma chamada API (Método 2) ou ferramenta de terceiros (Métodos 3-5) para recuperá-los como dados estruturados.

Posso usar a API ActivityPub para salvar posts do Mastodon gratuitamente?

Sim. A API REST do Mastodon é aberta e não autenticada para todas leituras públicas. Você pode buscar timelines, statuses individuais, e resultados de busca com simples HTTP GET requests para endpoints como https://mastodon.social/api/v1/timelines/public ou https://mastodon.social/api/v2/search. Rate limits são cerca de 300 requests por janela de 5 minutos por IP.

ThreadGrab suporta arquivamento do Mastodon?

Sim. ThreadGrab roteia requests Mastodon pela mesma API REST aberta que toda instância Mastodon implementa, então você pode arquivar posts de mastodon.social, fosstodon.org, hachyderm.io, ou qualquer outra instância através de um endpoint. O output é JSON normalizado ou Markdown que combina com o que ThreadGrab retorna para X e Bluesky.

O que é o toot CLI?

toot é o cliente de linha de comando Mastodon de terceiros mais popular, instalável com pip install toot. Suporta postar, ler, buscar, marcar e seguir de qualquer terminal. Seus comandos toot search e toot bookmarks são particularmente úteis para arquivamento scriptado do Fediverso.

Posso arquivar uma instância inteira do Mastodon localmente?

Só se você for o admin da instância: Mastodon envia tarefas rake oficiais (tootctl media backfill, tootctl backup) que fazem dump de todo status, arquivo de mídia, e linha de banco de dados em um arquivo tar. Não-admins podem usar Mastodon-CLI mais a API REST pública para raspar conteúdo público em escala, mas posts privados e DMs não podem ser arquivados sem acesso admin.

Qual método de arquivamento Mastodon é melhor para preparação de dados LLM?

ThreadGrab é o mais ergonômico para workflows LLM porque produz Markdown limpo ou JSON normalizado diretamente. A API REST Mastodon bruta e o SDK atproto ambos exigem processamento adicional para converter registros em formatos LLM-friendly. toot CLI é ótimo se você quer leituras autenticadas (seus bookmarks, seus DMs); Mastodon-CLI é a escolha certa para exports de alto volume.

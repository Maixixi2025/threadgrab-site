Capcat 2026: Arquivamento de Artigos Web CLI para Criadores

4 de Julho, 2026 · 8 min de leitura · Guia

Em Julho de 2026, uma nova ferramenta de codigo aberto apareceu no cenario de criadores de conteudo: Capcat (capcat.org) — um aplicativo CLI e TUI que arquiva qualquer artigo web como Markdown e HTML limpos. Enquanto o ThreadGrab foca em threads sociais do X, Bluesky e LinkedIn, o Capcat preenche o nicho complementar de arquivamento de paginas web.

Este guia explica o que o Capcat faz, como se compara ao ThreadGrab, e como combinar ambos para um fluxo completo de arquivamento em 2026.

TL;DR. Capcat e uma ferramenta CLI/TUI gratuita e de codigo aberto que baixa artigos web e os salva como Markdown. E um arquivador de paginas web, enquanto o ThreadGrab e um coletor de conteudo social. As duas se complementam: use ThreadGrab para threads do X, posts do Bluesky e newsletters do LinkedIn; use Capcat para artigos vinculados e paginas de referencia.

O Que e o Capcat?

Capcat e um aplicativo de linha de comando e interface de terminal disponivel em capcat.org. Dada uma URL, ele busca a pagina, extrai o conteudo principal e o salva como Markdown junto com uma copia HTML. Nao requer conta, chave de API ou assinatura.

A saida Markdown remove anuncios e navegacao, dando a voce o texto e imagens em formato portatil. O HTML preserva o layout original.

Como o Capcat Funciona: Fluxo Basico

O Capcat opera em dois modos: CLI rapido para URLs unicas e TUI interativo para lote.

# Save a single article as Markdown
capcat save https://example.com/blog/article --output ~/archive/

# Save with both Markdown and HTML
capcat save https://example.com/blog/article --format markdown,html

# Interactive TUI mode (browse, batch, search)
capcat tui

O modo TUI mostra uma interface onde voce pode colar URLs, navegar por artigos, pesquisar e exportar. Para criadores que usam Obsidian, VS Code ou gerenciam bases de conhecimento, o TUI se encaixa naturalmente.

Capcat vs ThreadGrab: Papeis Complementares

  • ThreadGrab e otimizado para conteudo social: threads do X, X Articles, Bluesky e newsletters LinkedIn. Entende a estrutura especifica da plataforma.
  • Capcat e otimizado para artigos web gerais: blogs, Substack, noticias, documentacao. Extrai o corpo principal e remove o resto.
# Save a social thread via ThreadGrab
threadgrab thread https://x.com/user/status/12345 \
  --output ~/archive/social/ \
  --with-media

# Save a linked reference article via Capcat
capcat save https://example.com/reference-page \
  --output ~/archive/articles/

Cenarios para Criadores

1. Pesquisa para Newsletter

Voce le 10-20 artigos por semana. Capcat arquiva cada um como Markdown. Quando sentar para escrever, tem o material em formato que seu editor ou IA le diretamente.

2. Base de Conhecimento

Plataformas sociais sao efemeras. Capcat da um vault Markdown local e pesquisavel de tudo que voce citou. Com git, sua base sobrevive a deterioracao das plataformas.

# Batch archive a reading list from a file
cat reading-list.txt | capcat batch --output ~/kb/articles/

# Search your archive
capcat search --keyword "MCP server" ~/kb/articles/

3. Dados para Treinamento de IA

Markdown e o formato preferido para fine-tuning e RAG. Capcat produz Markdown limpo sem necessidade de limpeza HTML.

Exemplo: Arquivando Newsletter do LinkedIn

# Step 1: Save the LinkedIn newsletter post via ThreadGrab
threadgrab thread https://www.linkedin.com/pulse/my-newsletter-edition-123 \
  --output ~/archive/linkedin/

# Step 2: The newsletter links to 3 external articles.
# Archive each one with Capcat
capcat save https://source-1.com/article --output ~/archive/sources/
capcat save https://source-2.com/blog-post --output ~/archive/sources/
capcat save https://source-3.com/research --output ~/archive/sources/

# Step 3: Everything is in one date-organized vault
ls ~/archive/2026-07/

Integracao em Pipeline

# Pipe a URL list from any source (RSS reader, bookmark export, API response)
curl -s "https://api.example.com/bookmarks" | jq -r '.[].url' | capcat batch

# Archive all open tabs from a browser bookmark export
cat bookmarks.html | grep -oP 'href="\K[^"]+' | capcat batch --output ~/archive/tabs/

Esta abordagem e familiar para usuarios do ThreadGrab. Os dois CLIs compartilham a filosofia: local primeiro, viavel em scripts.

FAQ

O Capcat e gratuito e de codigo aberto?

Sim. O Capcat e totalmente codigo aberto disponivel em capcat.org. Nao ha nivel pago, conta ou limites de API.

O Capcat baixa imagens e midia?

Sim. O Capcat extrai imagens inline do artigo e as salva junto ao Markdown. Para video, o Markdown mantem as URLs originais.

Posso usar Capcat e ThreadGrab juntos?

Absolutamente. ThreadGrab lida com conteudo social (X, Bluesky, LinkedIn). Capcat lida com artigos web. Juntos formam um arquivo completo.

O Capcat tem extensao de navegador?

Nao. Capcat e um aplicativo CLI. Para captura pelo navegador, use extensoes "Save as Markdown" ou envie URLs via linha de comando.

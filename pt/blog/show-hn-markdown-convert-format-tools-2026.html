Show HN: 6 Ferramentas Markdown-para-Formato para Ficar de Olho (2026)

14 de Setembro de 2026 · 10 min de leitura · por ThreadGrab

Markdown vem ganhando silenciosamente a cauda longa das ferramentas de conteúdo há anos, mas os últimos doze meses no Show HN tornaram o padrão impossível de ignorar. Desenvolvedores estão convertendo Markdown — um formato de texto puro com 20 anos — em slides, apresentações, decks de PowerPoint, HTML para e-mail, PDFs prontos para KDP, EPUBs e, no caminho inverso, qualquer-coisa-para-Markdown para pipelines de IA. Este é um passeio por seis dos lançamentos mais interessantes de 2026, o que cada um faz bem e onde eles se encaixam na cadeia de ferramentas de quem escreve.

Para quem vive no X e no Bluesky, isso importa duas vezes: Markdown é o formato-fonte canônico que você deveria manter para seus posts longos, e essas ferramentas são como você realmente os publica no formato que seu público espera.

Resumo. O cenário de conversão Markdown de 2026 se divide claramente em três direções: Markdown para apresentação (Deckstream para decks ao vivo no navegador, MkSlides para HTML estático, Slidown para .pptx), Markdown para documento publicável (Email.md para HTML de e-mail, markdown-to-book para PDF/EPUB KDP) e qualquer coisa para Markdown (anyto.md, mirando exatamente a economia de janela de contexto da IA). Escolha a direção primeiro; o formato depois; a ferramenta por último.

1. Deckstream — Markdown Vira um Deck Slidev, Ao Vivo no Navegador

Deckstream foi lançado no Show HN em 12/09/2026. O argumento é "apresentações, na velocidade do pensamento": você digita Markdown à esquerda e assiste a um deck Slidev totalmente renderizado à direita, depois publica um link compartilhável com um clique. Não há instalação local, não há CLI, não há autoria de tema — o motor de renderização é Slidev (Vue + Vite) e a URL compartilhável é o próprio deck, não uma exportação estática.

O engajamento no Show HN foi modesto (1 ponto, 0 comentários até o momento da escrita), mas o ângulo é interessante para um caso de uso específico: palestras técnicas em que você quer que o mesmo deck renderize idêntico para cada espectador sem se preocupar com fontes de PDF, notas do apresentador quebradas ou alguém abrindo o arquivo na versão errada do PowerPoint.

Onde o Deckstream brilha

  • Instalação zero. Só navegador; a URL compartilhável é o entregável.
  • Pré-visualização ao vivo enquanto você digita. Se você já usou Slidev localmente, Deckstream é o mesmo fluxo sem o toolchain de Node.
  • Fonte única de verdade. O arquivo Markdown é o deck. Nada de往返 de .pptx.

Onde ele atrapalha

  • Beta fechado. Sem repositório público, sem CLI, sem fallback local se o serviço cair.
  • Lock-in no Slidev. Você herda o ecossistema de plugins e temas do Slidev — flexível, mas não dá para portar facilmente para Google Slides ou PowerPoint.
  • Offline é por sua conta. Sem exportação, um Wi-Fi ruim de conferência é um risco real.

2. Email.md — O Sucesso de 380 Pontos que Finalmente Faz Markdown Funcionar no Outlook

Email.md (Show HN 24/03/2026, 380 pontos, 94 comentários) foi o vencedor disparado de engajamento entre os lançamentos de conversão Markdown de 2026. O autor é dancablam; a página descreve como "HTML responsivo, seguro para e-mail, que renderiza perfeitamente em qualquer cliente", e o motor subjacente é MJML, o que significa que a saída é tabelas e estilos inline até o fim — a única coisa que sobrevive ao Gmail, Apple Mail e Outlook ao mesmo tempo.

O que diferencia o Email.md da dúzia de outros projetos "MD para e-mail" é a extensão de sintaxe: ::: highlight, ::: divider, ::: callout, e diretivas inline como {width=600} em imagens. Você escreve Markdown; você envia o e-mail; nunca precisa olhar para o HTML resultante.

$ npm install emailmd

# newsletter.md
::: highlight compact center bg=#0A0A0A color=#FFE500
**MOONBEAN MONTHLY · NO. 012 · TORRAS FRESCAS**
:::

# LANÇAMENTOS. ZERO DESCAFEINADO.

![Bancada de café](coffee.jpg){width="600"}

::: callout center
# DFY-X7U
:::

$ npx emailmd build newsletter.md -o out/
# > out/newsletter.html  (seguro no Outlook, responsivo, pronto para enviar)

3. Slidown — Markdown para PowerPoint, Sem IA no Pipeline

Slidown (Show HN 07/07/2026, 2 pontos) é do Songmu e vive em github.com/Songmu/slidown. É o irmão .pptx do k1LoW/deck, a ferramenta Markdown-para-Google-Slides, e ambos compartilham o mesmo formato Markdown e mapeamento de elementos de slide. Slidown grava arquivos .pptx autônomos via um escritor OOXML em Go puro — sem dependência de Office de terceiros, sem IA na geração, sem licença Microsoft.

Instalável via Homebrew (brew install Songmu/tap/slidown) ou go install. 31 estrelas no GitHub na escrita, licença MIT.

# deck.md
---
title: Palestra sobre slidown
---

# Primeiro slide

## Um subtítulo

- um bullet
- **negrito** e *itálico* e `código`

---

# Segundo slide

Um parágrafo com um [link](https://example.com).

$ slidown apply deck.md
# Wrote deck.pptx (2 slide(s))

O enquadramento "sem IA" é deliberado: o autor está posicionando o Slidown contra uma onda de ferramentas 2025-2026 "Markdown para PPT com IA" que alucinam conteúdo de slide. Se seu Markdown já é canônico, você quer um compilador determinístico, não um modelo.

4. MkSlides — O Gerador de Slides Estáticos Estilo MkDocs

MkSlides (Show HN 27/11/2025, 78 pontos, 15 comentários — então fica entre o final de 2025 e a conversa de 2026) é um gerador de site estático Python voltado especificamente para slideshows. O conjunto de comandos e o formato do arquivo de configuração são deliberadamente modelados no MkDocs, o que significa que qualquer pessoa que já publicou documentação de projeto com MkDocs consegue montar um deck em uns dez minutos.

Os slides são escritos em Markdown, tematizados via um único arquivo YAML, e a saída é HTML Reveal.js puro. Você pode hospedar em qualquer lugar onde arquivos estáticos rodem: uma branch do GitHub Pages, um bucket S3 ou um site no Cloudflare Pages. 474 estrelas no GitHub, licença MIT, no PyPI como mkslides.

Quando escolher MkSlides

  • Você quer entregar um deck como arquivos, não como serviço ao vivo.
  • Você tem uma pasta de slides, não um arquivo único. MkSlides trata cada .md como um deck e gera uma página-índice.
  • Você já usa MkDocs e quer a mesma memória muscular.

5. markdown-to-book — PDF e EPUB Prontos para KDP a Partir de uma Única CLI

vpuna/markdown-to-book (Show HN 06/03/2026, 6 pontos, 5 comentários) faz uma coisa e faz especificamente: converte um manuscrito Markdown em arquivos PDF e EPUB formatados para Amazon KDP e outros pipelines de impressão sob demanda. 39 estrelas, MIT, primeiro commit em 05/03/2026. Se você já tentou publicar um livro auto-publicado e perdeu um fim de semana brigando com templates do LibreOffice, esta é a ferramenta.

6. anyto.md — Direção Inversa: Qualquer Coisa em Markdown Amigável para IA

anyto.md (vlucas, Show HN 02/09/2026, 7 pontos) é a única ferramenta nesta lista que vai no caminho contrário. Seu trabalho é converter URLs, PDFs, arquivos Office, HTML e imagens em Markdown limpo para você alimentar um modelo de IA sem pagar tokens por layout e metadados. A alegação de marketing é algo em torno de 86% menos tokens quando o Markdown convertido vai para um LLM, comparado a enviar o PDF ou HTML original direto.

O plano gratuito é de cinco conversões sem conta; além disso você paga por conversão via chave de API. O log de auditoria de conversões é pesquisável, o que é útil se você roda um pipeline de agentes que converte a mesma fonte mais de uma vez.

Por que a direção inversa importa para arquivos sociais

Se você salva um thread ou Article do X para ler depois, e mais tarde quer resumir com um LLM, o HTML que você raspou é a pior entrada possível. anyto.md é uma forma de obter Markdown limpo a partir de HTML salvo; a API pública de fetch de threads do ThreadGrab é outra — ela devolve o texto da thread diretamente, não o HTML da página.

Como Escolher: Uma Árvore de Decisão em Três Perguntas

  1. Qual é o destino? Slides (Deckstream, MkSlides, Slidown), e-mail (Email.md), um livro publicado (markdown-to-book) ou uma janela de contexto de IA (anyto.md ou seu próprio conversor)?
  2. Você precisa de uma URL ao vivo ou de um arquivo estático? Ao vivo = Deckstream (renderizado no navegador). Estático = MkSlides (arquivos HTML) ou Slidown (.pptx) ou markdown-to-book (PDF/EPUB).
  3. O Markdown já é canônico, ou você quer que a IA preencha os slides? Canônico = Slidown, MkSlides, markdown-to-book, Email.md, Deckstream. Assistido por IA = a dúzia de ferramentas "MD para PPT com IA" de 2025-2026, que estão explicitamente fora desta lista.

Perguntas Frequentes

Qual ferramenta Markdown do Show HN teve o maior engajamento em 2026?

Email.md (Markdown para HTML responsivo e seguro para e-mail, saída MJML, compatível com Outlook) atingiu 380 pontos e 94 comentários quando foi lançado em 24/03/2026 — por ampla margem o maior engajamento entre os lançamentos de conversão Markdown de 2026.

Qual a diferença entre Deckstream e MkSlides?

Deckstream renderiza apresentações Slidev (Vue + Vite) ao vivo enquanto você digita em um navegador e publica uma URL compartilhável — sem instalação local, sem CLI. MkSlides monta slideshows HTML estáticos a partir de Markdown via Reveal.js e roda localmente como um gerador de site estático em Python — você publica arquivos HTML onde quiser.

Posso converter Markdown para PowerPoint sem um serviço de IA?

Sim. Slidown (Songmu, MIT, Go) grava arquivos .pptx autônomos via um escritor OOXML em Go puro, sem dependências de Office de terceiros e sem IA no pipeline de geração. É a ferramenta irmã de k1LoW/deck (Markdown para Google Slides).

Existe alguma ferramenta Markdown para PDF/EPUB prontos para KDP?

Sim — vpuna/markdown-to-book (39 estrelas, MIT, primeiro commit em 05/03/2026) é uma CLI que converte texto Markdown em PDF e EPUB formatados para Amazon KDP e pipelines similares de impressão sob demanda.

E se eu precisar ir no caminho inverso — converter PDFs e documentos Office para Markdown?

anyto.md (vlucas, Show HN 02/09/2026, 7 pontos) converte URLs, PDFs, arquivos Office, HTML e imagens em Markdown pronto para IA. O argumento é economia de janela de contexto: o Markdown convertido consome cerca de 86% menos tokens do que enviar o arquivo original direto para um modelo.

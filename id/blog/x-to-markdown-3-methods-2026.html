X ke Markdown 2026: 3 Cara Menyimpan Thread & Artikel X

8 Juni 2026 · 8 menit baca · oleh ThreadGrab

X (sebelumnya Twitter) menampung puluhan juta thread, artikel, dan diskusi publik setiap hari. Jika Anda seorang peneliti, penulis, atau praktisi AI yang ingin menyimpan konten itu untuk bacaan offline, analisis, atau data pelatihan LLM, Anda memerlukan cara yang andal untuk mengonversi konten X ke Markdown bersih.

Kabar baiknya adalah 2026 menawarkan setidaknya tiga opsi solid, masing-masing cocok untuk alur kerja yang berbeda. Panduan ini mencakup setiap metode secara rinci sehingga Anda dapat memilih yang sesuai dengan kebutuhan Anda — apakah Anda mengambil satu hot take untuk ChatGPT atau menjalankan skrip malam yang mengarsipkan setiap thread dari penulis favorit Anda.

TL;DR. Gunakan tweet.md untuk konversi satu kali tercepat (ganti x.com dengan tweet.md di URL mana pun). Gunakan API publik ThreadGrab untuk akses terprogram gratis ke thread dan profil. Gunakan mode baca browser atau layanan baca-nanti untuk penyimpanan cepat Artikel X individu. Pengguna power menggabungkan ketiganya.

Apa yang Berubah di 2026 untuk Pengarsipan Konten X?

Dua hal membuat X-ke-Markdown secara signifikan lebih mudah tahun ini. Pertama, tweet.md meluncurkan layanan yang sangat sederhana: ganti x.com dengan tweet.md di URL postingan mana pun dan dapatkan Markdown bersih, dioptimalkan untuk LLM. Ini berfungsi dengan postingan individu, thread, dan bahkan halaman profil. Kedua, ekosistem LLM yang lebih luas — ChatGPT, Claude, Gemini CLI, Hermes Agent, Cursor — telah menjadikan Markdown sebagai format pertukaran default untuk data pelatihan dan jendela konteks, mendorong permintaan untuk ekstraksi teks yang bersih dan efisien token.

Metode 1: tweet.md — Konversi Satu Baris

tweet.md

Situs web: tweet.md

Kelebihan: Tanpa pengaturan, dioptimalkan untuk LLM, berfungsi di perangkat apa pun dengan browser, gratis untuk postingan tunggal.

Kekurangan: Memerlukan internet, tidak dapat diskrip tanpa paket kunci API mereka, tingkat gratis mungkin membatasi pengguna berat.

tweet.md adalah cara paling sederhana untuk mengonversi postingan X ke Markdown. Anda tidak menginstal apa pun — cukup edit URL. Setiap postingan dan profil di X memiliki URL publik; mengganti domain dari x.com ke tweet.md memberi Anda versi Markdown yang dirender dari konten yang sama.

# URL postingan X asli
#   https://x.com/paulg/status/1234567890123456789
#
# Ganti saja x.com dengan tweet.md:
#   https://tweet.md/paulg/status/1234567890123456789
#
# Halaman dimuat sebagai Markdown bersih. Salin dan tempel
# ke ChatGPT, Claude, atau editor Markdown mana pun.

Outputnya mencakup nama penulis, teks postingan, statistik engagement, dan dalam kasus thread, seluruh thread digabungkan sebagai satu dokumen Markdown. tweet.md juga menawarkan file skill untuk agen AI (instal melalui npx skills add tweet-md/skill) sehingga Claude Code, Cline, atau Hermes Agent dapat mengambil konten X dengan cepat.

tweet.md baru-baru ini ditampilkan di Product Hunt. Ini sangat berguna ketika Anda sedang dalam chat LLM dan menemukan thread X yang ingin Anda analisis oleh model — ganti URL, salin Markdown, dan tempelkan.

Kapan menggunakan tweet.md

  • Anda membaca X di ponsel atau laptop dan ingin menyimpan satu thread untuk nanti.
  • Anda ingin memberikan thread X ke ChatGPT atau Claude untuk peringkasan atau analisis.
  • Anda ingin membagikan versi thread X yang bersih dan diformat dengan rekan kerja tanpa screenshot.

Metode 2: API Publik ThreadGrab — Pengarsipan Massal Terprogram

ThreadGrab

Situs web: threadgrab.com

Kelebihan: Dapat diskrip, mendukung Bluesky juga, gratis dan tanpa akun, mengembalikan JSON terstruktur yang dapat Anda sesuaikan.

Kekurangan: Memerlukan kenyamanan baris perintah (curl, jq, atau bahasa skrip), tidak secepat penggantian URL.

ThreadGrab mengekspos API publik yang mengembalikan konten thread X sebagai JSON terstruktur. Ini adalah pilihan yang tepat ketika Anda perlu mengotomatisasi: mengambil batch thread dari penulis favorit Anda, mengarsipkannya ke disk setiap malam, atau membangun pipeline riset khusus.

# Ambil thread terbaru pengguna sebagai JSON
curl -s https://threadgrab.com/api/profile/paulg \
  | jq '.[:3] | .[] | {author, text_length: (.text | length)}'

# Simpan seluruh thread sebagai Markdown ke file lokal
curl -s https://threadgrab.com/api/profile/paulg \
  | jq -r '.[] | "# \\(.author)\\n\\n\\(.text)\\n---"' > paulg-archive.md

API ThreadGrab mengembalikan data thread dalam skema yang dapat diprediksi: handle penulis, nama tampilan, teks postingan, statistik engagement, dan timestamp. Anda dapat memprosesnya dengan bahasa skrip apa pun — Python, Bash, Node.js — dan mengonversinya ke Markdown, JSON, atau CSV.

Tidak seperti tweet.md, ThreadGrab juga mendukung postingan Bluesky melalui API terbuka AT Protocol. Jika Anda mengarsipkan konten dari beberapa platform sosial, ThreadGrab adalah titik masuk tunggal Anda.

Kapan menggunakan API ThreadGrab

  • Anda memelihara arsip riset diskusi X dan menginginkan pembaruan batch malam hari.
  • Anda sedang membangun dataset untuk pelatihan atau fine-tuning LLM.
  • Anda ingin mengarsipkan konten X dan Bluesky melalui satu antarmuka.
  • Anda membutuhkan data terstruktur (timestamp, hitungan engagement) selain teks.

Metode 3: Mode Baca Browser dan Layanan Baca-Nanti

Pocket, Matter, atau Pembaca Bawaan Browser

Setiap browser utama memiliki mode baca. Aplikasi khusus seperti Pocket dan Matter menambahkan sinkronisasi dan anotasi.

Kelebihan: Berfungsi untuk halaman web apa pun, bukan hanya X; tanpa pengaturan; baik untuk penyimpanan artikel tunggal.

Kekurangan: Tidak ada akses terprogram; Artikel X dirender dengan baik tetapi balasan thread sering hilang; format tidak konsisten.

Ini adalah metode dengan usaha paling rendah. Setiap browser utama memiliki mode baca (Ctrl+Shift+R di desktop, atau ikon halaman di bilah alamat di seluler). Ketika Anda membuka X Article atau tampilan HTML thread, mode baca menghilangkan sidebar, postingan yang disarankan, dan iklan, hanya menyisakan konten.

# Pintasan keyboard untuk mode baca:
#   Chrome / Edge:   F9 atau Ctrl+Shift+R
#   Firefox:         F9
#   Safari:          Cmd+Shift+R (tombol Baca di bilah alat)
#
# Setelah dalam mode baca, salin-tempel teks bersih ke
# editor Markdown favorit atau aplikasi pencatatan.

Layanan baca-nanti khusus seperti Pocket dan Matter melangkah lebih jauh: mereka menyimpan artikel ke perpustakaan Anda, menyinkronkan di seluruh perangkat, dan sering mengekspos lapisan sorotan/anotasi. Pocket dan Matter memungkinkan Anda mengekspor artikel yang disimpan sebagai teks biasa atau HTML, yang kemudian dapat Anda konversi ke Markdown dengan alat seperti pandoc.

Kapan menggunakan mode baca / layanan baca-nanti

  • Anda hanya menyimpan konten X sesekali dan tidak ingin belajar alat baru.
  • Anda sudah menggunakan Pocket atau Matter untuk postingan blog dan menginginkan daftar bacaan terpadu.
  • Anda membaca X Articles (long-form) daripada postingan pendek ber-thread — mode baca menangani long-form jauh lebih baik daripada penggabungan thread pendek.

Membangun Alur Kerja Otomatis dengan Ketiganya

Banyak pengguna power menggabungkan metode untuk pipeline lengkap. Berikut adalah contoh dunia nyata: seorang peneliti yang mengikuti 20 akun X dan menginginkan arsip siap-LLM yang dikirim ke vault Obsidian mereka setiap pagi.

#!/bin/bash
# Arsip X malam untuk Obsidian (berjalan jam 6 pagi melalui cron)

USERS=("paulg" "kelseyhightower" "swyx" "levelsio")
OUTPUT_DIR="$HOME/obsidian-vault/inbox/x-threads"
mkdir -p "$OUTPUT_DIR"

for user in "${USERS[@]}"; do
  curl -s "https://threadgrab.com/api/profile/$user" \
    | jq -r '.[] | "# \\(.author)\\n\\(.text)\\n---"' \
    > "$OUTPUT_DIR/$user-$(date +%Y-%m-%d).md"
done

echo "Mengarsipkan ${#USERS[@]} profil ke $OUTPUT_DIR"

Pipeline ini menggunakan API ThreadGrab untuk pengambilan batch, menghasilkan Markdown bersih yang dapat diindeks Obsidian, dan membuka pintu untuk tweet.md ketika peneliti menemukan satu thread menarik selama hari kerja dan menginginkannya di chat LLM mereka segera.

Pro tip. Jika Anda menggunakan agen coding AI seperti Claude Code, Cline, atau Cursor, instal skill tweet.md dengan npx skills add tweet-md/skill. Agen kemudian dapat mengambil URL X apa pun sebagai Markdown dengan cepat selama sesi Anda, tanpa Anda meninggalkan chat.

FAQ

Apa itu tweet.md dan bagaimana cara menggunakannya?

tweet.md mengonversi postingan atau thread X publik menjadi Markdown bersih. Cukup ganti x.com dengan tweet.md di URL dan Anda mendapatkan Markdown. Gratis untuk postingan individu dan menawarkan paket kunci API untuk pengguna berat.

Bisakah saya menyimpan thread X secara terprogram tanpa tweet.md?

Ya. ThreadGrab menawarkan API publik gratis yang mengembalikan data thread sebagai JSON terstruktur. Gunakan curl untuk mengambil konten thread, kemudian konversikan JSON ke Markdown dengan jq atau skrip Python pendek.

Apakah tweet.md lebih baik dari ThreadGrab untuk menyimpan thread X?

Mereka melayani kebutuhan berbeda. tweet.md dioptimalkan untuk input LLM satu kali cepat. ThreadGrab unggul dalam akses terprogram, alur kerja batch, dan dukungan Bluesky. Banyak pengguna power menggabungkan keduanya.

Bagaimana cara menyimpan X Articles (long-form) sebagai Markdown?

Mode baca browser (Ctrl+Shift+R) atau aplikasi baca-nanti seperti Pocket dan Matter memberi Anda teks bersih dari URL X Article mana pun. tweet.md juga berfungsi dengan URL Article. API ThreadGrab juga mendukungnya.

Apa metode terbaik untuk mengirim konten X ke ChatGPT atau Claude?

tweet.md dirancang khusus untuk input LLM: Markdown bersih dengan boilerplate minimal. Salin dan tempel langsung ke chat mana pun. Untuk injeksi massal, API ThreadGrab dapat mengambil batch beberapa thread sebagai blok Markdown.

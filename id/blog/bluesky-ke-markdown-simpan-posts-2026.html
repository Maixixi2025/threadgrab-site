Bluesky ke Markdown 2026: Simpan Postingan sebagai Markdown

10 Agustus 2026 · 10 menit baca · Panduan

Bluesky dibangun di atas AT Protocol (“atproto”), dan pilihan itu menjadikannya salah satu platform sosial yang paling mudah diekspor di tahun 2026. Setiap postingan publik, thread, dan feed penulis disajikan oleh API publik yang mengembalikan JSON bersih — tanpa akun, tanpa token, dan tanpa jabat tangan rate limit untuk pembacaan dasar. Artinya, “Bluesky ke Markdown” bukan sekadar solusi khusus; itu adalah alur kerja normal yang didukung.

Panduan ini menunjukkan mengapa menyimpan postingan Bluesky sebagai Markdown layak dilakukan, cara kerja endpoint publik atproto, dan rute tercepat menuju arsip lokal yang portabel — dari satu curl hingga skrip batch yang bisa Anda jalankan untuk seluruh timeline.

Ringkasan singkat: Bluesky mengekspos postingan publik melalui public.api.bsky.app tanpa autentikasi. Selesaikan handle menjadi DID, ambil feed, ubah teks record menjadi Markdown, dan Anda memiliki salinan tahan lama yang dapat dicari dalam hitungan detik. Ini pola yang sama “ambil kontennya, simpan Markdown-nya” yang digunakan ThreadGrab untuk X — dan berlaku juga untuk Bluesky.

Mengapa Menyimpan Postingan Bluesky sebagai Markdown

Bluesky lebih terbuka daripada kebanyakan jaringan, tetapi terbuka tidak berarti permanen. Postingan bisa dihapus, handle bisa berubah, dan masalah akun atau instance bisa membawa daftar bacaan Anda ikut hilang. Jika sebuah postingan penting — catatan riset, thread berguna, referensi yang nanti Anda kutip — satu-satunya salinan yang benar-benar Anda kendalikan adalah yang ada di disk Anda sendiri.

Markdown adalah format yang tepat untuk pekerjaan ini karena tiga alasan konkret:

  • Ini teks polos. Anda bisa mencarinya, menggrep-nya, dan membacanya di editor atau aplikasi catatan apa pun sekarang maupun sepuluh tahun lagi.
  • Ini bisa diperiksa versinya. Masukkan ke git dan Anda bisa membandingkan postingan dengan versi yang diedit, yang penting saat melacak perubahan atau koreksi.
  • Ini mengisi alur kerja AI. LLM, agen, dan pipeline RAG mencerna Markdown jauh lebih bersih daripada gambar tangkapan atau web scraper.

Screenshot menjaga pikselnya, bukan isinya. Markdown menjaga kata-kata, struktur, tautan, dan metadata — itulah sebabnya komunitas pengarsipan menstandardisasinya.

Bagaimana API Publik Bluesky Bekerja

Bluesky berjalan di atas atproto, dan jalur pembacaan sengaja dibuat publik. Dua endpoint melakukan hampir semua pekerjaan pengarsipan:

  • com.atproto.identity.resolveHandle — mengubah handle seperti @bsky.app menjadi DID yang persisten (did:plc:...).
  • app.bsky.feed.getAuthorFeed (dan getPosts) — mengembalikan postingan terbaru untuk DID tersebut sebagai JSON, termasuk teks postingan dan cap waktu.

URL dasarnya adalah https://public.api.bsky.app. Referensi endpoint lengkap dipublikasikan oleh Bluesky di docs.bsky.app, dan endpoint feed mendokumentasikan bentuk respons yang persis. Tidak ada langkah masuk untuk konten publik: Anda menyelesaikan, mengambil, dan selesai. Responsnya adalah JSON terstruktur, jadi mengubahnya menjadi Markdown hanya beberapa baris kode dalam bahasa apa pun.

Catatan: Anda hanya memerlukan app password (token) jika ingin membaca postingan privat atau melakukan tindakan pada akun. Pengarsipan publik murni tidak pernah menyentuh autentikasi, yang juga memudahkan otomatisasi dengan skrip di server headless atau dalam cron job.

Metode 1 — Simpan Satu Postingan dengan curl

Cara tercepat untuk mengambil satu postingan Bluesky sebagai Markdown adalah memanggil API publik secara langsung. Pertama, selesaikan handle penulis menjadi DID:

curl "https://public.api.bsky.app/xrpc/com.atproto.identity.resolveHandle?handle=bsky.app"

Respons mengembalikan identifikasi persisten:

{ "did": "did:plc:z72i7hdynmk6r22z27h6tvur" }

Sekarang ambil feed penulis, simpan hanya field yang Anda butuhkan. Satu baris pendek Python mengubah JSON menjadi bullet Markdown bersih:

import json, urllib.request
did = "did:plc:z72i7hdynmk6r22z27h6tvur"
url = ("https://public.api.bsky.app/xrpc/app.bsky.feed.getAuthorFeed"
       "?actor=" + did + "&limit=5")
data = json.load(urllib.request.urlopen(url))
for item in data["feed"]:
    rec = item["post"]["record"]
    print("## " + rec.get("createdAt", "")[:10])
    print(rec.get("text", "") + "\n")

Jalankan dan Anda mendapatkan blok Markdown yang dapat dibaca per postingan — tanggal sebagai judul, teks sebagai paragraf. Itulah seluruh alur kerja untuk penyimpanan manual sekali saja.

Metode 2 — Arsipkan Seluruh Timeline dalam Batch

Untuk postingan terbaru dari satu akun utuh, tambahkan pagination. getAuthorFeed mengembalikan cursor yang Anda teruskan kembali untuk mengambil halaman berikutnya, jadi loop kecil menangkap semuanya tanpa melewatkan apa pun:

import json, urllib.request, urllib.parse
did = "did:plc:z72i7hdynmk6r22z27h6tvur"
cursor = None
for page in range(3):
    params = {"actor": did, "limit": 50}
    if cursor:
        params["cursor"] = cursor
    url = ("https://public.api.bsky.app/xrpc/app.bsky.feed.getAuthorFeed?"
           + urllib.parse.urlencode(params))
    data = json.load(urllib.request.urlopen(url))
    for item in data.get("feed", []):
        rec = item["post"]["record"]
        print("## " + rec.get("createdAt", "")[:10] + "\n"
              + rec.get("text", "") + "\n")
    cursor = data.get("cursor")
    if not cursor:
        break

Setiap kali dijalankan, skrip menambahkan postingan ke file Markdown, dan cursor menjamin Anda melihat semua halaman. Jalankan mingguan di dalam cron job dan Anda mendapatkan arsip bergulir yang dapat dicari untuk akun Bluesky mana pun yang Anda ikuti.

FAQ

Bisakah saya menyimpan postingan Bluesky sebagai Markdown?

Ya. API publik atproto Bluesky menyajikan postingan sebagai JSON polos tanpa autentikasi, jadi Anda bisa mengambil postingan, thread, atau feed penulis lengkap dan memformatnya sebagai Markdown di perangkat Anda. Alat khusus dan ekstensi browser juga merender postingan Bluesky sebagai Markdown dengan satu klik.

Apakah API Bluesky memerlukan akun atau token?

Untuk postingan publik, tidak. Endpoint publik atproto public.api.bsky.app memungkinkan Anda menyelesaikan handle menjadi DID dan mengambil feed penulis atau postingan individual tanpa masuk. Anda hanya memerlukan app password jika ingin membaca konten privat atau bertindak atas nama akun.

Bagaimana cara mendapatkan postingan Bluesky sebagai Markdown?

Cara termudah adalah mengganti domain pada URL postingan atau memanggil API publik secara langsung. Misalnya, selesaikan handle dengan com.atproto.identity.resolveHandle, lalu panggil app.bsky.feed.getAuthorFeed atau getPosts dan ubah teks record menjadi Markdown. Skrip lokal dapat mengotomatiskan ini untuk setiap postingan yang ingin Anda simpan.

Tweet.md Stabil 2026: Pelajaran dari Minggu Sepi

28 Agustus 2026 · 8 menit baca · Lanskap

Beberapa minggu penuh berita; yang satu ini tidak. tweet.md, konverter X-ke-Markdown yang diluncurkan pada Mei 2026, sudah sepi sejak entri changelog terakhirnya pada 27 Agustus 2026 ("demo gratis" ditambah tanggal publikasi dan edit di setiap post). Homepage stabil, dateModified JSON-LD menunjukkan 2026-08-24, dan sinyal produk terbaru adalah — dalam kata-kata tweet.md sendiri — "Try a no-charge demo". Itu seluruh minggu ini.

Bagi seorang pengarsip, minggu yang sepi adalah data. Ini menunjukkan alat mana yang selamat dari gejolak peluncuran pertama, fitur mana yang menjadi table-stakes, dan celah mana yang tidak dikebut siapa pun. Postingan ini adalah retrospeksi lanskap alat: di mana pasar X-ke-Markdown berada di akhir Agustus 2026, kapan tweet.md adalah pilihan yang tepat, dan di mana ThreadGrab menutup sisanya.

Kesimpulan singkat: tweet.md kini adalah konverter stabil, berbayar, khusus X, dengan ergonomi API agen yang kuat (Next.js di Cloudflare, paket kredit $5–$49, frontmatter Obsidian YAML, profil-sebagai-Markdown). ThreadGrab adalah pengarsip gratis, multi-platform (X + Bluesky + LinkedIn), dengan API profil publik dan UI trilingual. Gunakan tweet.md saat Anda ingin snapshot profil di vault Obsidian Anda; gunakan ThreadGrab saat Anda ingin arsip gratis, tahan lama, multi-platform yang tidak bergantung pada halaman harga satu vendor.

Apa itu tweet.md, tiga bulan kemudian

tweet.md diluncurkan 2026-05-17 sebagai konverter post, thread, Articles, dan profil X. Slogan homepage-nya persis apa yang dilakukannya: Convert X/Twitter posts, threads, Articles, and profiles to clean Markdown for LLMs, agents, research, and archives. Just swap x.com for tweet.md. Situs ini adalah build Next.js (App Router) di Cloudflare, disajikan dari edge Singapura dengan server-side rendering penuh — H1, empat tab input (Single post / Thread / X Article / Profile), dan JSON-LD semuanya ada di respons pertama, bukan shell client-side.

Permukaan produk lebih sempit dari yang disarankan homepage. Outputnya tepat dua format: markdown (default) atau obsidian (Markdown dengan frontmatter YAML untuk vault Obsidian). Dokumentasinya tegas: “plain text, never JSON”. Pilihan query mencakup format, thread (default branch-5, rentang 2–500), userinfo, stats, metadata, dan apikey. Endpoint-nya adalah /i/api/convert dan /i/api/profile. Tidak ada Bluesky, tidak ada LinkedIn, tidak ada Mastodon, tidak ada Threads.

Berapa harga tweet.md, dan apa yang tidak dinyatakan

Harga berupa paket kredit: $5 / 200 kredit, $19 / 1.000, $49 / 3.000 (per kredit $0,025 → $0,019 → $0,0163). Tanpa langganan, tanpa per-kursi. Autentikasi berupa API key, header Bearer, cookie sesi, atau daftar IP tepercaya — beberapa kunci per akun diizinkan. Demo terkontrol untuk profil uji *t-twmduser gratis.

Yang tidak dipublikasikan: batas rate. Situs ini tidak mencantumkan batas rate di mana pun yang terlihat, yang penting untuk alat yang mengenakan biaya per panggilan. Jika Anda membangun agen di atas tweet.md, Anda mempercayai throttle diam-diam vendor — risiko yang bisa Anda hindari dengan membeli paket kredit dan memperlakukan setiap permintaan sebagai pengeluaran terukur. Untuk alur riset yang menarik ribuan post sekaligus, tidak adanya batas rate yang dinyatakan adalah bendera kuning.

Di mana ThreadGrab menutupi area berbeda

ThreadGrab berada di kategori yang sama — menangkap konten sosial publik sebagai Markdown — tetapi dengan tiga perbedaan struktural yang penting bagi pengarsip.

  • Multi-platform: X, Bluesky, LinkedIn, dan (melalui pipeline tangkap headless) halaman web apa pun yang dirender. tweet.md khusus X saja.
  • Gratis, tanpa akun: pipeline arsip ThreadGrab dan endpoint publik /api/profile/{username} tidak memerlukan API key maupun pembayaran.
  • UI trilingual: EN / PT / ID. tweet.md khusus bahasa Inggris, tanpa permukaan lokalisasi di source-nya.

Bentuk gratis + multi-platform + trilingual itulah sebabnya cakupan ThreadGrab tumpang tindih dengan tweet.md di X tetapi meluas ke platform tempat tweet.md tidak bisa mengikuti — dan mengapa kedua alat ini saling melengkapi, bukan saling menggantikan.

Alur arsip "minggu sepi"

Saat tidak ada yang meluncurkan, langkah yang tepat adalah memperkuat arsip yang ada. Berikut alur yang menggabungkan snapshot profil ramah-Obsidian dari tweet.md dengan tangkap thread Markdown gratis dan tahan lama dari ThreadGrab, disimpan berdampingan dalam satu folder agar teks yang bisa dibaca dan provenance terstruktur berjalan bersama.

my-archive/
  tweet-md-profiles/
    2026-08-28-handle-profile.md        # Obsidian YAML frontmatter
  threadgrab-threads/
    2026-08-28-same-thread.md           # clean Markdown, no metadata
    2026-08-28-same-thread.json         # structured sidecar (re-fetchable)
  README.md

Gunakan tweet.md untuk snapshot profil yang ingin Anda simpan di vault Obsidian (frontmatter YAML, tag, dataview-friendly). Gunakan ThreadGrab untuk thread-nya sendiri (teks lengkap + sidecar JSON yang bisa Anda ambil ulang nanti). Kedua format sengaja berbeda: tweet.md memberi Anda node knowledge-graph; ThreadGrab memberi Anda sitasi. Sebuah arsip membutuhkan keduanya.

Cek tangkap cepat

Untuk tangkap sesekali, tes paling sederhana adalah apakah pola URL yang sudah Anda punya bekerja pada alat yang sedang Anda gunakan. Berikut bentuk yang kedua alat harapkan, berdampingan:

# tweet.md: ganti host-nya
https://x.com/handle/status/123...  ->  https://tweet.md/i/status/123...

# ThreadGrab: handle yang sama, API profil publik
https://threadgrab.com/api/profile/handle

# Keduanya mengembalikan Markdown; tweet.md menambahkan frontmatter YAML
# Obsidian pada flag format obsidian, ThreadGrab mengembalikan Markdown bersih
# plus sidecar JSON opsional yang bisa Anda ambil ulang.

Jika Anda mendapati diri mengganti x.com dengan tweet.md di bilah URL beberapa kali sehari, Anda membayar kenyamanan Obsidian. Jika Anda mendapati diri menempel URL profil ThreadGrab yang sama ke sebuah skrip, Anda sedang merangkai jalur arsip yang tahan lama. Keduanya adalah langkah jujur.

Kapan menggunakan yang mana, dalam tiga aturan singkat

  • Gunakan tweet.md saat hasilnya adalah snapshot profil atau thread ramah-Obsidian, saat Anda tidak keberatan membayar per panggilan, dan saat Anda hanya butuh X.
  • Gunakan ThreadGrab saat hasilnya adalah arsip gratis, tahan lama, dan multi-platform, saat Anda butuh API publik tanpa auth, atau saat pembaca Anda tidak hanya berbahasa Inggris.
  • Gunakan keduanya saat Anda ingin node YAML Obsidian dan thread Markdown yang tahan lama, dan Anda bersedia mengeluarkan beberapa kredit untuk mendapatkan frontmatter yang benar.

Apa arti sebenarnya pasar yang stabil

Minggu yang sepi bukan kategori mati — melainkan kategori yang menemukan bentuknya. tweet.md memiliki ceruk X-only, Obsidian-first, API-untuk-agen; ThreadGrab memiliki ceruk multi-platform, gratis, trilingual. Tidak ada yang berlomba menyerap yang lain. Pembacaan jujurnya adalah bahwa pasar X-ke-Markdown pada Agustus 2026 tersegmentasi, bukan mengkonsolidasi: konverter yang bertahan adalah yang memilih keunggulan struktural (berbayar + agent-first, atau gratis + multi-platform) dan berhenti mengejar sisi lain.

Bagi pengarsip, itu berita baik. Dua vendor yang bertahan lebih baik daripada satu. Risiko yang harus diperhatikan ada di setiap sisi: batas rate yang tidak dinyatakan dan cakupan platform tunggal tweet.md; ketergantungan ThreadGrab pada platform sosial yang tidak mengubah permukaan API publik mereka. Tidak ada yang akan hilang bulan ini — keduanya layak dimasukkan ke dalam alur arsip jangka panjang.

FAQ

Apakah tweet.md gratis?

Sebagian. tweet.md menjual paket kredit ($5 / $19 / $49) dan menawarkan demo gratis untuk profil uji *t-twmduser. Untuk konversi profil atau thread sungguhan, Anda membayar per panggilan. Tidak ada langganan dan tidak ada tier gratis untuk penggunaan produksi.

Platform apa yang didukung tweet.md?

Hanya X / Twitter — post, thread, Articles, dan profil. Tidak ada dukungan Bluesky, LinkedIn, Mastodon, atau Threads di permukaan produk yang terlihat.

Bisakah tweet.md menghasilkan JSON atau data terstruktur?

Tidak. Dokumentasinya tegas: outputnya adalah teks polos, baik Markdown maupun Markdown dengan frontmatter YAML Obsidian. Jika Anda butuh JSON terstruktur, Anda harus parse Markdown sendiri atau gunakan alat lain.

Apakah tweet.md mempublikasikan batas rate?

Tidak. Tidak ada batas rate per detik atau per hari yang dipublikasikan di mana pun di dokumentasi yang terlihat. Perlakukan setiap permintaan sebagai pengeluaran terukur terhadap saldo kredit Anda dan lakukan backoff pada respons 429 daripada mengandalkan kuota yang dinyatakan.

Apa beda ThreadGrab dengan tweet.md?

ThreadGrab gratis, multi-platform (X + Bluesky + LinkedIn + web headless), dan hadir dengan API profil publik tanpa auth. tweet.md berbayar, khusus X, dan hadir dengan output YAML ramah-Obsidian. Gunakan yang cocok dengan bentuk arsip Anda; keduanya layak disimpan.

Apakah saya harus pindah dari tweet.md ke ThreadGrab (atau sebaliknya)?

Hanya jika bentuk arsip Anda berubah. Jika Anda butuh cakupan multi-platform, tangkap tak terbatas gratis, atau UI trilingual, pindah ke ThreadGrab. Jika Anda butuh frontmatter YAML Obsidian, ergonomi API agen, dan Anda senang membayar per panggilan, tetap dengan tweet.md. Banyak pengarsip menjalankan keduanya berdampingan.

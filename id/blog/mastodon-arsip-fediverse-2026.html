Arsip Mastodon Fediverse 2026: 5 Cara Simpan Post, Media & Feed

1 Agustus 2026 · 11 menit baca · oleh ThreadGrab

Mastodon dan Fediverse yang lebih luas melewati titik balik pada 2026. mastodon.social saja sekarang melayani lebih dari 3,3 juta pengguna aktif bulanan dengan 183 juta status yang diterbitkan; instance khusus seperti fosstodon.org, hachyderm.io, dan mastodon.online menambahkan 300 ribu pengguna lagi di antaranya. Baik Anda seorang jurnalis yang melacak berita penting, peneliti yang membangun dataset longitudinal, atau kreator konten yang menggunakan kembali post mereka sendiri untuk artikel panjang, Anda memerlukan cara yang andal untuk mengarsipkan konten Mastodon sebelum sebuah instance mati atau moderator menghapus utasan.

Fediverse berjalan di ActivityPub -- protokol yang sama yang menggerakkan Mastodon, Misskey, Pleroma, Akkoma, Ghost, PeerTube, dan Pixelfed. Fondasi bersama tersebut membuat pengarsipan berbasis ActivityPub lebih mudah daripada mengikis platform proprietary mana pun, karena setiap node mengekspos API publik yang kompatibel. Panduan ini mencakup lima metode terbukti untuk mengarsipkan post, media, dan feed instance Mastodon secara keseluruhan di 2026, dari bookmark hingga pengikisan federasi penuh.

Ringkasan. Gunakan bookmark bawaan Mastodon untuk penyimpanan kasual. Gunakan REST API Mastodon untuk akses terprogram tanpa autentikasi. Gunakan ThreadGrab untuk pengarsipan lintas platform (Mastodon + X + Bluesky dalam satu antarmuka). Gunakan toot CLI untuk alur kerja terminal. Gunakan Mastodon-CLI untuk ekspor masif dan backup tingkat instance.

Mengapa Pengarsipan Mastodon Penting di 2026

Tiga tren menjadikan pengarsipan Mastodon sangat mendesak tahun ini. Pertama, populasi Fediverse hampir tiga kali lipat sejak perpindahan Twitter 2022, dengan instance individual secara rutin menampung 60rb-300rb pengguna dan jutaan post publik. Kedua, instance bisa hilang dalam semalam: moderator sukarela kelelahan, tagihan hosting tidak dibayar, atau satu keluhan DMCA memicu shutdown server,带走 setiap post publik bersamanya. Ketiga, desain terbuka ActivityPub berarti tidak ada kunci API, paywall, atau pendaftaran developer yang dibutuhkan untuk akses baca pada konten publik -- alat apa pun yang dapat berbicara HTTP dapat mengarsipkan Fediverse.

Berbeda dari X yang membatasi akses API ke tingkatan berbayar, dan berbeda dari Instagram atau TikTok yang mengunci endpoint baca di balik gating app yang disetujui, server ActivityPub mempublikasikan seluruh timeline publik mereka melalui HTTP gratis. Anda tidak perlu mendaftarkan app, tidak perlu berlangganan, dan tidak perlu membayar siapa pun. Ini menjadikan Fediverse jaringan percakapan publik paling dapat diarsipkan di 2026.

Metode 1: Bookmark Bawaan Mastodon -- Penyimpanan Tanpa Usaha

Bookmark Bawaan Mastodon

Tersedia di semua app Mastodon resmi (web, iOS, Android, klien pihak ketiga) sejak Mastodon 4.0 (2023).

Pro: Tanpa setup, privat, dapat dicari dalam akun, berfungsi di setiap app resmi.

Kontra: Tidak ada export lewat UI web, bookmark hidup dan mati bersama akun, tanpa operasi batch, tanpa media terlampir.

Mastodon memperkenalkan bookmark di versi 4.0 (November 2023), dan bekerja seperti bookmark sosial lain yang pernah Anda gunakan. Klik ikon bookmark di post mana pun, dan ia akan disimpan ke daftar privat yang hanya terlihat oleh Anda. Bookmark dapat dicari di UI web dan app mobile resmi, dan sinkron di antara perangkat jika Anda login ke akun yang sama.

Bookmark sempurna untuk penggunaan kasual -- Anda melihat utasan menarik di feed utama, bookmark, dan kembali nanti untuk dibaca ulang. Tapi punya langit-langit keras: tidak ada tombol export. Jika Anda ingin migrasi, membagikan, atau menganalisis koleksi bookmark, Anda butuh API (Metode 2) atau alat pihak ketiga (Metode 3-5).

Kapan menggunakan bookmark bawaan

  • Anda sesekali menyimpan post dan hanya membacanya kembali di dalam Mastodon.
  • Anda menggunakan Mastodon di banyak perangkat dan ingin daftar bacaan tersinkronisasi.
  • Anda tidak memerlukan konten tersimpan di luar Mastodon, dan percaya pada keandalan jangka panjang instance Anda.

Metode 2: REST API Mastodon -- Pendekatan Terbuka, Tanpa Auth

API Publik Mastodon (v1 + v2)

URL dasar: https://<instance>/api/v1/ dan .../api/v2/ -- endpoint baca tidak butuh autentikasi.

Pro: Sepenuhnya gratis, tanpa pendaftaran app, terdokumentasi baik di docs.joinmastodon.org, berfungsi dengan klien HTTP apa pun.

Kontra: Rate limit per IP (300 request per 5 menit di kebanyakan instance), butuh keakraban dengan kosa kata ActivityPub, biner media butuh fetch terpisah.

Setiap instance Mastodon mengekspos REST API yang mencerminkan UI web Mastodon dengan dekat. Anda dapat mengambil timeline publik, status individual, feed hashtag, hasil pencarian, dan listing direktori instance -- semua dengan HTTP GET request sederhana dan tanpa login. Permukaan API stabil lintas instance karena setiap server mengimplementasikan kode Mastodon yang sama.

# Mengambil timeline lokal instance Mastodon mana pun
curl -s "https://fosstodon.org/api/v1/timelines/public?limit=3" \
  | jq '[.[] | {user: .account.username, content: .content[0:120]}]'

# Mengambil status spesifik berdasarkan ID numerik
curl -s "https://mastodon.social/api/v1/statuses/113305367338692164" \
  | jq '{id: .id, user: .account.username, content: .content[0:200]}'

# Mencari lintas indeks lokal instance mana pun
curl -s "https://mastodon.social/api/v2/search?q=ActivityPub+archiving&limit=10" \
  | jq '.statuses[] | {user: .username, content: .content[0:120]}'

Konsep kunci dalam model data Mastodon adalah ID numerik (integer 64-bit, sering dirender sebagai Snowflake). Setiap status, akun, dan lampiran media punya ID yang stabil. Setelah Anda punya URL status, Anda dapat mengekstrak instance dan ID, lalu mengambil post yang sama dari alat apa pun yang berbicara REST API. Berbeda dari aktivitas bertanda tangan ActivityPub, REST API adalah permukaan JSON-only yang lebih sederhana yang ditujukan untuk app klien.

Rate limit diterapkan per IP dan per token akses, dengan kebanyakan instance standar di 300 request per jendela 5 menit untuk trafik tidak terautentikasi. Untuk pengarsipan personal, cron job harian tetap berada dalam batas. Untuk pengumpulan skala besar, Anda butuh token akses (login sekali, simpan token) atau alat crawling federasi.

Kapan menggunakan REST API Mastodon

  • Anda nyaman dengan curl atau bahasa scripting seperti Python atau Node.js.
  • Anda ingin menarik JSON untuk analisis hilir (input LLM, konstruksi dataset, migrasi konten).
  • Anda hanya butuh konten publik, dan tidak masalah melewati media atau post yang butuh login.

# Arsipkan akun Mastodon mana pun lewat ThreadGrab (tanpa login)
curl -s "https://threadgrab.com/api/mastodon/account/mastodon.social/mastodon" \

Karena setiap server Mastodon mengimplementasikan endpoint REST yang sama, ThreadGrab dapat bertanya instance mana yang ingin Anda query dan merutekan request secara otomatis. Anda tidak perlu belajar perbedaan antara deployment mastodon.social dan fosstodon.org -- mereka mengekspos permukaan API yang sama, jadi ThreadGrab memperlakukan mereka sama.

Outputnya adalah JSON bersih yang dapat Anda transformasi ke format apa pun: Markdown untuk posting blog dan konteks LLM, CSV untuk analisis spreadsheet, teks biasa untuk pengindeksan pencarian. Post Mastodon menyertakan URL asli, handle penulis (dengan instance-nya, mis. @user@fosstodon.org), dan timestamp yang dinormalisasi yang dapat Anda urutkan terhadap konten platform lain.

Metode 4: toot CLI -- Perangkat Pengguna Terminal Ahli

toot (CLI untuk Mastodon)

pip install toot -- CLI Mastodon pihak ketiga paling populer, ditulis dengan Python.

Pro: Paritas fitur penuh dengan UI web, login satu perintah, dirancang untuk scripting, berfungsi dengan instance mana pun.

Kontra: Membutuhkan pendaftaran app Mastodon (satu klik di pengaturan), menambahkan dependensi Python, kurang ergonomis untuk ekspor masif.

toot adalah CLI de facto untuk Mastodon. Mengekspos API baca dan tulis lengkap di shell yang ramah: toot post mempublikasikan status, toot timeline mencetak timeline utama Anda, toot search menjalankan query kata kunci. Untuk pengarsip, perintah toot bookmark, toot whois, dan toot search sangat berguna karena memungkinkan triase dan menangkap konten tanpa meninggalkan terminal.

# Instal dan login (jalankan sekali)
pip install toot
toot login --instance fosstodon.org
# Jendela browser terbuka; salin kode auth kembali; toot menyimpan secara lokal

# Cari dan simpan 5 hasil pertama
toot search "ActivityPub arsip 2026" --limit 5 \
  | tee mastodon-pencarian-2026-08-01.txt

# Daftar bookmark Anda secara terprogram (bagus untuk mengisi arsip)
toot bookmarks --limit 20 | tee bookmark-saya.txt

# Periksa pengguna mana pun -- pengikut, bio, jumlah post
toot whois --user @Gargron@mas.to | head -40

toot menangani penyimpanan token login untuk Anda, jadi Anda hanya perlu mengautentikasi sekali per instance per perangkat. Ini teman yang brilian untuk pipeline shell: pipakan toot search ke jq, lalu ke tee, dan Anda punya skrip arsip harian dalam 4 baris.

Kapan menggunakan toot CLI

  • Anda tinggal di terminal dan ingin akses Mastodon tanpa tab browser.
  • Anda ingin mengautentikasi sekali dan menggunakan token yang sama untuk posting, bookmark, dan membaca.
  • Anda membangun pipeline arsip berbasis shell (cron, bash, fish, zsh).

Metode 5: Mastodon-CLI -- Ekspor Masif dan Backup Tingkat Instance

Mastodon-CLI + task rake (alat admin)

npm install -g mastodon-cli untuk non-admin, atau RAILS_ENV=production tootctl media backfill untuk admin.

Pro: Operasi masif, mendukung ratusan ribu post per sesi, menangkap biner media, mencakup backup admin untuk seluruh instance.

Kontra: Setup lebih berat dari metode lain, Mastodon-CLI kurang dipelihara aktif dibanding toot, backup tingkat instance butuh akses admin.

Ketika Anda perlu mengarsipkan ribuan post -- atau konten seluruh instance -- Anda meraih Mastodon-CLI atau task rake resmi tootctl. Mastodon-CLI adalah alat Node.js yang menyediakan varian batch-friendly dari endpoint REST umum, dengan logika retry dan dukungan resume untuk ekspor panjang.

# Instal Mastodon-CLI secara global
npm install -g mastodon-cli

# Login sekali (berbasis env, aman untuk cron)
export MASTODON_TOKEN=" fediverse-activitypub-arsip-md.txt

# Untuk admin instance: dump semuanya (statuses + media + DB)
tootctl media backfill --concurrency 20
tootctl backup --path /var/backups/mastodon/

Untuk pengguna non-admin, sweet spot Mastodon-CLI adalah grabs masif tingkat hashtag dan akun -- dapat menarik ribuan post dalam satu sesi, dengan retry bawaan di rate limit dan pelaporan progres. Untuk admin, task rake tootctl yang dibundel adalah cara kanonik untuk membackup instance sebelum migrasi server atau shutdown.

Kapan menggunakan Mastodon-CLI / tootctl

  • Anda perlu mengarsipkan lebih dari satu hari post dari pengguna atau hashtag.
  • Anda menjalankan migrasi instance dan butuh backup server yang luas.
  • Anda ingin mengunduh biner media, bukan hanya konten teks.

Membangun Pipeline Pengarsipan Mastodon Lengkap

Berikut cara kreator konten dapat menggabungkan metode ini menjadi alur kerja arsip Mastodon harian yang juga menangkap X dan Bluesky:

#!/bin/bash
# Pipeline arsip harian Fediverse + X + Bluesky (cron jam 7 pagi)
# Menggabungkan ThreadGrab API untuk penarikan lintas platform + penyimpanan file

MASTODON_INSTANCE="fosstodon.org"
ACCOUNTS=("Gargron@mas.to" "mcpheywood@mastodon.social" "fosstodon@fosstodon.org")
OUTPUT_DIR="$HOME/fediverse-arsip/$(date +%Y/%m)"
mkdir -p "$OUTPUT_DIR"

for acct in "${ACCOUNTS[@]}"; do
  HANDLE="${acct%@*}"
  curl -s "https://threadgrab.com/api/mastodon/account/${MASTODON_INSTANCE}/${HANDLE}" \
    | jq -r '.[] | "### @\(.user)\n\(.text)\n---\n"' \
    > "$OUTPUT_DIR/mastodon-$HANDLE.md"
  echo "Tersimpan Mastodon $acct: $(wc -l < "$OUTPUT_DIR/mastodon-$HANDLE.md") baris"
done

echo "Arsip Fediverse lengkap untuk $(date +%Y-%m-%d)"

Pipeline ini berjalan harian via cron, mengorganisir arsip berdasarkan tahun dan bulan, dan menggunakan ThreadGrab karena skrip yang sama juga dapat mengarsipkan handle Bluesky dan profil X tanpa modifikasi -- hanya URL yang berubah. Jurnalis kemudian dapat memberi arsip Markdown ke LLM untuk perangkuman, pencarian, atau deteksi tren lintas Fediverse.

Tip pro. Untuk fleksibilitas maksimum, gabungkan ThreadGrab untuk baca lintas platform, REST API Mastodon untuk investigasi ad hoc, dan toot untuk bookmarking terminal selama acara langsung. ThreadGrab menangani normalisasi Fediverse + X + Bluesky; API native dan CLI memberi Anda kontrol penuh saat dibutuhkan.

FAQ

Apakah Mastodon punya bookmark bawaan seperti Bluesky?

Ya. Mastodon punya bookmark bawaan sejak versi 4.0 (akhir 2023). Bersifat privat dan dapat dicari di dalam akun Anda, tapi tidak seperti Bluesky, Anda tidak dapat mengekspornya melalui UI web -- Anda butuh panggilan API (Metode 2) atau alat pihak ketiga (Metode 3-5) untuk mengambilnya sebagai data terstruktur.

Bisakah saya menggunakan API ActivityPub untuk menyimpan post Mastodon secara gratis?

Ya. REST API Mastodon terbuka dan tidak butuh autentikasi untuk semua pembacaan publik. Anda dapat mengambil timeline, status individual, dan hasil pencarian dengan HTTP GET request sederhana ke endpoint seperti https://mastodon.social/api/v1/timelines/public atau https://mastodon.social/api/v2/search. Rate limit sekitar 300 request per jendela 5 menit per IP.

Apakah ThreadGrab mendukung pengarsipan Mastodon?

Ya. ThreadGrab merutekan request Mastodon lewat REST API terbuka yang sama yang diimplementasikan setiap instance Mastodon, jadi Anda dapat mengarsipkan post dari mastodon.social, fosstodon.org, hachyderm.io, atau instance lainnya melalui satu endpoint. Outputnya adalah JSON atau Markdown yang dinormalisasi yang cocok dengan yang ThreadGrab kembalikan untuk X dan Bluesky.

Apa itu toot CLI?

toot adalah klien baris perintah Mastodon pihak ketiga paling populer, dapat diinstal dengan pip install toot. Mendukung posting, membaca, mencari, bookmark, dan mengikuti dari terminal mana pun. Perintah toot search dan toot bookmarks sangat berguna untuk pengarsipan Fediverse berbasis skrip.

Bisakah saya mengarsipkan seluruh instance Mastodon secara lokal?

Hanya jika Anda admin instance: Mastodon menyediakan task rake resmi (tootctl media backfill, tootctl backup) yang membuang setiap status, file media, dan baris basis data ke arsip tar. Non-admin dapat menggunakan Mastodon-CLI ditambah REST API publik untuk mengikis konten publik secara masif, tapi post privat dan DM tidak dapat diarsipkan tanpa akses admin.
